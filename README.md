# Hello World

Website pertama saya — satu halaman statis berisi "Hello World".

🔗 Live: https://yoganatha-pranashakti.vercel.app

## Struktur

- `index.html` — seluruh isi website (HTML + CSS, tanpa build step)

## Menjalankan secara lokal

Buka file `index.html` di browser, atau jalankan server statis sederhana:

```bash
npx serve .
```

## Deploy

Website ini di-deploy ke Vercel. Karena hanya berisi file statis, tidak perlu
konfigurasi tambahan — Vercel otomatis menyajikan `index.html` sebagai halaman utama.
